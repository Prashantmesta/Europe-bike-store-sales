# Europe-bike-store-sales
# 📊 Sales Analysis Dashboard – Power BI

## 🔍 Project Overview
This project analyzes sales performance using Power BI.  
The dashboard helps business users track revenue, profit, and sales trends.

## 🧾 Dataset
- Source: Excel sales dataset
- Records: Sales transactions
- Key Columns:
  - Order Date
  - Product
  - Category
  - Region
  - Sales
  - Profit

## 🛠 Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## 📈 Key KPIs
- Total Sales
- Total Profit
- Profit Margin
- Sales by Region
- Monthly Sales Trend

## 📊 Dashboard Features
- Interactive slicers (Date, Region, Category)
- Trend analysis
- Region-wise performance
- KPI cards
